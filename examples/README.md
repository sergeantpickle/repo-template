# Growth Trajectories

These examples are non-normative. They show how the same standard produces different structures from different starting conditions.

- [seed-to-mature.md](seed-to-mature.md) — one small project grows through several coordination levels without pre-creating the later structure.
- [starting-at-twenty.md](starting-at-twenty.md) — a repository that already begins with source, tests, CI, deployment, and generated files.
- [recovering-from-sprawl.md](recovering-from-sprawl.md) — a README/HANDOFF/CHANGELOG system that has lost jurisdiction.
- [project-map.md](project-map.md) — when an INDEX/PROJECT map earns existence and when it is only a duplicate of the tree.
- [organization-scale.md](organization-scale.md) — how coordination pressure can grow from one maintainer/agent to organization scale without using headcount as a maturity threshold.
