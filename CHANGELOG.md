# Changelog

This changelog records changes to the Repository Growth Standard itself. It is not a development log or handoff record.

## 0.1.0 - 2026-11-07

### Added

- Defined the repository as an upstream growth standard rather than a copy-everything project scaffold.
- Added canonical-ownership, lifecycle-separation, progressive-growth, promotion, retirement, and enforcement rules.
- Added downstream adoption by version with explicit exceptions.
- Added artifact-routing guidance and maturity triggers.
- Added concrete growth and restraint examples, including README, handoff, and changelog contamination.
- Added a dated evidence review covering current vendor practice, independent benchmarks, and documentation-drift research.
- Added minimal starter adoption files and conservative project-audit tooling.

### Removed from the model

- Mandatory speculative project directories.
- A permanent project-wide handoff requirement.
- The assumption that every project needs an architecture document, research directory, decision directory, generated-docs directory, or execution-plan framework at initialization.
- The assumption that the upstream guide should be copied wholesale into downstream repositories.
