# Guide Index

`STANDARD.md` is the normative entry point. `rules.json` is the machine-readable catalog of stable rule IDs.

## Normative guidance

- [lifecycle.md](lifecycle.md) — information states, promotion, retirement, and conflict authority.
- [routing.md](routing.md) — canonical ownership for common repository information.
- [growth.md](growth.md) — triggers for adding organizational structure.
- [adoption.md](adoption.md) — downstream adoption, version checks, and deliberate updates.
- [audit.md](audit.md) — audit levels, heuristic limits, and exception semantics.

## Non-normative guidance

- [examples.md](examples.md) — quick routing/growth cases and links to deeper trajectories.
- [evidence.md](evidence.md) — dated research supporting the current standard.
- [../examples/README.md](../examples/README.md) — longer growth trajectories.

A new guide document should be created only when its responsibility cannot be cleanly owned by an existing document.
