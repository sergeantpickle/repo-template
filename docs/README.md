# Guide Index

`STANDARD.md` is the normative entry point. This directory contains the detailed guidance it delegates to and the evidence/examples used to maintain it.

## Normative

- [adoption.md](adoption.md) — downstream adoption, version checks, exceptions, and updates.
- [routing.md](routing.md) — canonical ownership for common repository information.
- [growth.md](growth.md) — evidence-based triggers for structural growth.

## Non-normative

- [examples.md](examples.md) — concrete growth, routing, and restraint examples.
- [evidence.md](evidence.md) — research supporting the current standard.

A new guide document should be created only when its responsibility cannot be cleanly owned by one of these files.
